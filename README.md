# Discord Theme - A modern theme for Discord
#### Disclaimer: This theme was originally based on [the Translucence Discord Theme by CapnKitten](https://github.com/CapnKitten/BetterDiscord/tree/master/Themes/Translucence). The initial idea was to create a theme with acrylic/Mica support, but that concept gradually faded over time. The project has since evolved into its own custom theme, featuring a more rounded design and several visual improvements for a cleaner and more polished look. It works especially well with Nitro Colors.

<hr>

## Usage

### [BetterDiscord](https://betterdiscord.app/)
> 1. Download and install "BetterDiscord" (Link above)
> 2. Click on "Releases", under "Assets" choose .zip file to get the theme.
> 3. Extract and drag the downloaded file to your themes folder.
> 4. Done!
### [Vencord](https://vencord.dev/download/)
> 1. Download and install "Vencord" (Link above)
> 2. Copy this 
```
https://haiporo9x88x.github.io/acrydisc/acrydisc.css
```
> 3. Go to "Discord User Settings" -> "Vencord Settings" -> "Themes" -> "Online Themes" -> Paste link to "Enter Theme Links..."
> 4. Done!
